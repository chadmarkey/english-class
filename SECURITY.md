# Security Policy

## Supported versions

Security work targets the latest public `main` and, when releases exist, the latest public
release. No backport promise is made for older commits or releases.

## Reporting a vulnerability

Do not disclose vulnerability details in a public issue. Open the repository's **Security**
tab and select **Report a vulnerability**. Include the affected version or commit, the
impact, and a minimal reproduction. Redact credentials and personal data, and use synthetic
examples.
